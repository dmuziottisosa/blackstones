# 01-strategy/

El cerebro estratégico. Cómo decidimos, a quién le hablamos, qué prometemos, qué decisiones tomamos.

## Contenido

| Archivo / carpeta | Qué es | Cuándo leer |
|---|---|---|
| `operating-principles.md` ⭐ | Principios operativos: filosofía, las 5 reglas, ciclo de decisión, sesgos a vigilar. | Antes de cualquier decisión grande. |
| `mechanism.md` | Las 5 piezas del mecanismo diferenciador. | Antes de cualquier copy / ad / cambio de oferta. |
| `avatars/` | Un doc por avatar. Carolina (principal), arquitecta, flipper, baño. | Antes de cualquier campaña o mensaje. |
| `decision-log/` | Registro de decisiones grandes con knowns / known unknowns / unknown unknowns. | Para entender por qué hicimos lo que hicimos, o para tomar una decisión nueva. |

## Reglas de esta carpeta

- Los docs acá son **layer-3 active beliefs** salvo que digan lo contrario en el header.
- Cualquier afirmación con `status: hypothesis` necesita plan de validación explícito.
- Cuando la realidad contradice un doc, **gana la realidad** y se actualiza el doc con fecha y razón (regla Brújula-no-Mapa).

## Cuándo se actualiza esta carpeta

- Cambia el avatar principal o sumamos uno secundario validado.
- Cambia el mecanismo (raro — debería ser estable).
- Toma una decisión grande que merece registro.
- Default: revisión cada 6 meses.
