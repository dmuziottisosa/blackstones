# layer-3-active-beliefs/

**Lo que creemos hoy que es verdad.** Síntesis de las layers 0, 1, 2 filtrada por nuestra realidad operativa.

## Qué va acá

- Conclusiones operativas que guían decisiones recurrentes y no caben en una sola carpeta funcional.
- Beliefs cross-cutting (atraviesan brand + strategy + marketing + product).
- Hipótesis testeables que aún no son convicción dura, marcadas con `status: hypothesis`.

## Reglas

- **Cualquier afirmación debe poder rastrearse a layer-1, layer-2 o layer-0.** Si no, es opinión sin base.
- **Cuando aparece evidencia que contradice → actualizar con fecha y razón.** La regla Brújula-no-Mapa es no negociable.
- **Status explícito en cada doc:** `high-confidence` / `medium-confidence` / `hypothesis` / `outdated` / `under-review`.
