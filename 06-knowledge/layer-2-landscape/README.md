# layer-2-landscape/

Investigación externa: lo que sabe el mundo fuera de BlackStones que es relevante para nosotros.

## Subcarpetas

| Carpeta | Qué vive ahí |
|---|---|
| `libros/` ⭐ | Síntesis de los libros canónicos (copywriting, marketing, behavioral econ, persuasión) |
| `competencia/` (pendiente) | Perfiles de competidores en CABA: web, ads, precios, plazos, posicionamiento |
| `benchmarks/` (pendiente) | Casos de estudio de ganadores en rubros adyacentes (servicios premium, B2C ticket alto) |
| `industry/` (pendiente) | Datos del rubro marmolería en Argentina: tamaño de mercado, dinámicas, regulación, materiales |

## Reglas

- **Layer-2 es referencial, no operativo.** Lo que se aplica vive en layer-3 o en carpetas funcionales.
- **Cuando un libro o caso external cambia una decisión nuestra,** se documenta el link en el doc de la decisión (`01-strategy/decision-log/`).
- **Default de revisión:** trimestral para libros, mensual para competencia (cambia rápido).
