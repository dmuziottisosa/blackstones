## Reglas de esta carpeta

- Cada framework tiene que terminar con sección **"Cómo lo aplicamos en BlackStones"**. Si no, es lectura sin acción.
- Captions tienen que pasar el test de Living (`00-brand/voice-tone/voice-tone.md`).
- Hooks que no convirtieron también se documentan (con tag `tested-failed`) — saber qué no funciona vale tanto como saber qué sí.
