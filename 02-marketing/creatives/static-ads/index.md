## 7. Reglas operativas para statics

- **Aspect ratio:** 4:5 default (mejor performance en feed Meta).
- **Logo:** bottom-right, 8-10% del ancho del frame. Integrado, no pegado. Usar exacto como se provee.
- **Test de Living:** sí o sí antes de generar el asset final.
- **Plazos en copy:** **15-20 días corridos**. Nunca "10 días". Nunca "3-4 semanas".
- **No mencionar VenarStones.** Ni en wink, ni en nostalgia.
- **No poner niños** en imágenes.
- **No mencionar coordinación con gremios** (carpinteros, plomeros).
- **No prometer "garantía"** salvo en sinterizado (25 años de fábrica) o por escrito.

---

## 8. Cómo se actualiza este index

- Cada static que se genera → se actualiza el status en la tabla.
- Cada static que gana → se anota la métrica + se mueve el archivo de prompt a la carpeta `library/` de meta-ads.
- Cada static que se descarta → tag `descartado` + razón en una línea.
- Cada vez que sumamos un avatar nuevo → sección nueva.
