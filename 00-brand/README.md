# 00-brand/

Identidad de BlackStones. Lo que NO se cambia sin decisión registrada.

## Subcarpetas

| Carpeta | Qué vive ahí |
|---|---|
| `visual-identity/` | Paleta, tipografías, logo rules, reglas anti-clínicas |
| `voice-tone/` | Cómo hablamos, qué decimos, qué nunca decimos. Test de Living. |
| `positioning/` | "No vendemos piedra, vendemos certeza." Frase ancla y por qué. |

## Reglas de esta carpeta

- Cambios acá impactan **todo el resto del repo**. Si tocás `visual-identity/`, los exports de la calc, los static ads y la landing tienen que reflejar el cambio.
- Los assets binarios (logo PNGs, imágenes de marca) no van acá — van en `site/public_html/logo/` para deploy y en `00-brand/visual-identity/assets/` (futuro) para versiones de trabajo.
- Cambio de marca = decision-log obligatorio en `01-strategy/decision-log/`.
